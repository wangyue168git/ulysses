# 安静版说明

安静版（分支 `quiet`，默认）和经典版（分支 `main`）用的是同一套规则和数据，区别只在界面：安静版尽量不让你看到价格。

## 页面

**手机端只有两页。**

- **航向（首页）**：最上面是「你拥有多少股」，下面是你写的三句话。没有价格和金额。
- **持仓**：饼图中间写的是指数占比；列表分三组：你的公司、指数、其他，只写股数和占比，规则允许加仓的标一个「可加」。点一行看详情。

**其余功能都收在持仓页的两个图标里。**

- 左上角的曲线图标：金额面板。金额默认模糊，按住眼睛 2 秒才显示；点「更新于」那一行才出现盈亏，同时曲线切成累计盈亏，几秒后收回。眼睛没打开时点了没有反应。
- 右上角的「⋯」：新增持仓、本月该买什么、纪律成绩单、年度回顾、AI 顾问（配置了才有）、首页设置、外观。

**冷静页**：切到后台再回来，如果离开超过 1 分钟，先看到一页只有一句话的冷静页，轻点才进入。

**电脑端只看不改**：左边是首页那幅字，右边是饼图和持仓；右上角可以打开金额面板。新增、修改、删除、改规则都在手机上做。

## 首页设置

手机端「⋯ → 首页设置」，或者直接改 `data/plan.json`：

```json
"home": {
  "hero": "auto",
  "symbols": [],
  "caption": "",
  "blocks": []
},
"creed": { "lines": ["买股票就是买公司", "不预测市场", "慢就是快"] }
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `hero` | `auto` | 自动：写了定投计划就是定投名单里持有最多的那一只，否则是占比最大的一只 |
| | `shares` | 指定持仓的数量，代码写在 `symbols` 里 |
| | `total` | 总资产（默认模糊） |
| | `none` | 什么都不显示 |
| `caption` | 文字 | 数字下面的一句说明，可不填 |
| `blocks` | `dca` / `structure` / `targets` | 首页还要显示的块：本月定投进度、结构、个股目标。默认都不显示 |
| `creed.lines` | 最多三句 | 首页竖排显示，第一句最大；每句尽量短。清空就不显示 |

「最近一次种下」那一行来自交易记录：最近一次是买入，印章是「种」；最近一次是卖出，印章是「收」。

## 字体

首页和冷静页用的是系统自带的楷体（苹果设备是「楷体-简」，Windows 是「楷体」）。没有楷体的设备会退回系统的衬线字体，排版不变。

## 换回经典版

```bash
git checkout main
```

数据目录不用动。`plan.json` 里的 `home` 经典版不认识，会忽略。
